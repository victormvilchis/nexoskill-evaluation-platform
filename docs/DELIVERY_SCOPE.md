# Alcance de la primera entrega

## Incluido

- Estructura frontend completa.
- Estructura backend hexagonal modular.
- Oracle y migraciones Flyway.
- Usuarios iniciales de desarrollo.
- Roles y permisos.
- Inicio de sesión.
- Cierre de sesión.
- Sesiones opacas mediante cookie segura.
- Bloqueo temporal por intentos fallidos.
- Panel de bienvenida administrador.
- Panel de bienvenida usuario.
- Auditoría funcional inicial.
- Integración Apache XAMPP -> Spring Boot.
- Scripts PowerShell de ejecución y despliegue.
- Pruebas unitarias y reglas ArchUnit.

## Preparado para crecer

Los módulos visuales de usuarios, preguntas, evaluaciones y resultados aparecen
como próximos componentes, pero no contienen funcionalidad en esta entrega.

## Fuera de alcance

- CRUD de usuarios.
- Recuperación de contraseña por correo.
- Cambio de contraseña.
- Banco de preguntas.
- Evaluaciones.
- Intentos.
- Calificación.
- Resultados.
- Suscripciones.
- Pagos.
- Almacenamiento de archivos.
- Observabilidad avanzada.
